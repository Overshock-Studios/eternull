# Eternull 1.3 Horror Redesign Notes

## Pillars

- The Corruption is an infection, not only a biome.
- The world should glitch and degrade, but remain playable.
- Players should have readable counterplay: daylight, isolation, removing active Null blocks, and config tuning.
- Corrupted mobs should usually be created by exposure, not direct spawning.

## Implemented First Pass

- Active Null block spread is slower and non-recursive.
- Active Null spread is night-gated by default, while caves and covered areas can remain dangerous.
- Dormant Null is an inactive/dead state.
- Null mobs leave limited corruption footprints instead of converting large areas every tick.
- Vanilla zombies, creepers, and spiders convert into corrupted variants after sustained active-corruption exposure.
- The Corruption biome uses vanilla-style hostile spawns; conversion creates the horror variants.
- Subtle particles and sculk-like sounds can occur near active corruption.
- Containers, block entities, air, liquids, bedrock, barriers, portal blocks, and command/structure blocks are protected from corruption replacement.

## Balance Direction

- Corruption should be scary because it is persistent and systemic, not because it instantly deletes a base.
- Spread rates should start conservative and be config-driven.
- Direct daylight should suppress surface spread when `corruptionSpreadsOnlyAtNight` is enabled.
- Conversion should require exposure time so players can rescue or kill mobs before they turn.
- Future cleansing mechanics should target active Null first and make dormant Null cheap to clear.

## Future Major Ideas

- Add a craftable ward/anchor block that creates a small anti-corruption radius.
- Add cleansing items using Nullite or Dark Core materials.
- Add corruption stages: active, dormant, deep, and ruptured.
- Let deep corruption create stronger ambience and rarer threats, but only after an area has been infected for a long time.
- Add biome-local visual glitches: particles, distorted sounds, flickering fog, or brief darkness pulses.
- Give Nullmob a rarer, more deliberate role such as guarding deep-corruption pockets instead of common biome spawning.
